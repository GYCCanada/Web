# GYC Canada Web

The public-facing conference website for GYC Canada (Generation of Youth for
Christ Canada).

Current architecture starts with [`CONTEXT.md`](./CONTEXT.md). Deployment is defined by
[`ADR 0009`](./docs/adr/0009-pinned-docker-deployment.md), and versioned Form/Submission
persistence by
[`ADR 0010`](./docs/adr/0010-versioned-form-definitions-and-relational-submissions.md).

Historical implementation sequences are retained under [`docs/`](./docs/), including the
completed [`2026 revival plan`](./docs/revival-plan.md); they are not current architecture
guidance.
